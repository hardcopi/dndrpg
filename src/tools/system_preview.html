The scale

Everything below is a var() out of assets/css/tokens.css, including this page's own layout. Contrast ratios are measured in the browser from the resolved values — nothing here states a number about itself.

Surfaces

Text — two greys, not three

--text-faint was #6b7480: 2.50:1 on the lightest surface, used 42 times, and 21 runs of it were also set below 12px. Corrected to the 4.5:1 floor it becomes #99a0aa — and --text-dim is #98a1ae. They are the same grey. On surfaces this close together there is room for exactly two legible weights, so the third level comes from size and weight instead.

Signals — mark and ink

A colour used as a mark (border, icon, fill) has to clear 3:1. The same colour used as ink (running text) has to clear 4.5:1. One value cannot do both without washing out: --danger lifted to 4.5:1 turns a red into a pink, and an error that does not look alarming has stopped working. So each signal has two forms. Gold and warn already clear both, so their ink is an alias.

Ornament — the one place the floor argues with the design

Unlit brass, for frames and filigree, deliberately not gold — gold means "you can act on this" and an ornate border in gold spends that signal on decoration. It was #6f5a34, 2.23:1, and it is the border of every HUD panel. Raised to exactly 3:1 and no further. This is the single change on this page that fights the stated intent: "metal at rest" wants to be dim. If the frames now read as too present, the honest fix is to stop using ornament as a load-bearing border, not to put it back under the line.

Parchment — the map's own palette

76 raw hex values were living outside :root, in a file whose own comment forbade it, and almost all of them were here. The consequence was concrete: the map is the middle of the play screen and it was the one part of the interface that could not be re-themed with the rest of it.

Terrain — what survived the tile map

These four read as dead weight in an audit and are not: BattleMapGen still generates rough ground, water, low cover and tall cover, and .bm-cell.is-* still paints them. They were named for a world map that stopped existing around them. Eight genuinely dead colours went with this pass.

Type — nine steps, replacing 63 values

--fs-2xs is a floor, not the smallest thing available. The shell probe found 21 runs of live text below 12px at every width from 360px to 1440px, smallest 9.6px, none of it scaling with the viewport. The three display sizes are fluid because a 48px hero on a 360px phone wraps four times.
