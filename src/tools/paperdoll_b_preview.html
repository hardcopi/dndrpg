Layers: back · base · armour · hair · off hand · main hand. Each part is a 192×320 style-b layer on one shared body; colours are swapped by ramp, never blended. The colour menu switches between 32, 64, 128 and 256-colour builds of the same paintings. State lives in the URL hash, e.g. #hair=hair_long&col-cloth=blue.
