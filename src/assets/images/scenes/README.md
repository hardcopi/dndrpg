Scene configs live in `assets/js/scenes-data.js`, keyed by location key. Each record has an image path, optional subtitle, exits keyed by destination location key with scene-box percentage x/y and icon, NPC positions keyed by NPC key, a list of searchable object labels/positions/actions, and an FX list using RivermarkFX options. To add a scene, add its image here and one config record.
